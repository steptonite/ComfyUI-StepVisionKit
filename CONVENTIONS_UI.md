# StepVisionKit — домовленості UI нод

Діє для всіх нод паку. Перші три ноди за цим стандартом — Depth Look (повний, простий, відео), 24.10.2026.
Токени й компоненти лежать у `web/svk_ui.css`, спільний JS — у `web/svk_ui.js`. Кольори й розміри міняються там, а не у файлах нод.

## Правила

1. **На ноді немає абзаців тексту.** Пояснення дається лише через `title`: підказка зʼявляється, коли тримаєш курсор над елементом. Видимими лишаються підпис (1–3 слова), число або стан.
2. **Вигляд один на всі ноди.** Колір ноди — `#2a2a2f`, тло — `#151518`, акцент — бурштин `--svk-accent`. Фіолетового чи неону немає.
3. **Нативні віджети Comfy, що дублюють картку, сховані** через `hideWidget` зі `svk_ui.js`. Їхні значення все одно зберігаються у workflow і йдуть у Run. Картка лише читає й пише ці віджети через `control(node, name, spec, label)`.
4. **На видноті 3–5 головних керувань.** Усе інше ховається під «⋯ ще» (`morePanel`). Порядок такий: кадр або превʼю → вибір (плитки або сегмент) → 3–4 повзунки → «ще».
5. **Висота ноди не росте від вмісту.** Картка має клас `svk-card svk-scroll` і гортається колесом усередині себе (`keepWheel`). Полотно Comfy під нею не масштабується. У Nodes 2.0 обгортка ноди сама перехоплює колесо й віддає полотну, тому `keepWheel`/`onWheel` ловлять його ще на `window` (capture). Висоту картки в Nodes 2.0 обмежує `--svk-card-max-h` (типово 560px), інакше нода росла б разом із «ще». Ctrl + колесо чи щипок і далі масштабують полотно. Висоту картки задає розмір ноди (`fitToNode`: міряє наживо рядки входів/виходів над карткою), а не стала цифра. Якщо картку можна гортати вниз, знизу видно пігулку «нижче ще» (`scrollHint`); її стан — `data-below`, не клас, бо Vue перезаписує className віджета.
6. **Кнопки — іконки в один ряд** (`.svk-ibtn` у `.svk-icons` або `.svk-bar`). Назва й гаряча клавіша вказані в `title`, стан «увімкнено» позначається класом `.is-on`.
7. **Два-три варіанти вибору показуються сегментом** (`.svk-seg`), випадний список для них не потрібен. Короткі підписи — «превʼю / фінал», повна назва — у `title`.
8. **Повзунок** (`.svk-sl`): назва й число стоять в одному рядку, повзунок займає всю ширину з заливкою до значення. Подвійний клік по назві повертає типове значення. Якщо діапазон більший за ~4000 кроків (px, fps), замість повзунка ставиться поле з числом.
9. **Чіпи ефектів переносяться на новий рядок** (`auto-fill, minmax(104px, 1fr)`; на вузькій картці — 2 колонки через `@container`). Підпис чіпа стоїть в один рядок без переносу складів; якщо не влазить — три крапки, повна назва в `title`. Тап вмикає або вимикає ефект. Перетяг чи колесо змінюють силу 0..2, яку видно як заливку чіпа.
10. **Лук має людську назву:** `presetLabel()` перетворює `look_v1` на «Лук v1». Імʼя файлу видно лише в `title`.
11. **Перевірка — у режимі Nodes 2.0.** Там назва ноди стоїть унизу й теж займає висоту. Ширина картки — 340–360 px, мінімальна висота DOM-віджета — 380–420 px.
13. **«ще» — завжди останній рядок картки на всю ширину** (`moreSummary`): іконка, слово, лічильник схованих налаштувань, стрілка. Однаково на всіх нодах.
14. **Рядок етапів** (`stageLine`): під превʼю нода показує, що робить зараз — «чекає в черзі → читає кадри → запуск рушія → кадр k / N · ~залишок → змішування → готово за N с», або «з кешу» / помилку. Python шле `render_proc.stage(unique_id, ...)` (подія `svk.stage`), воркер — рядок `STAGE <назва>`.
12. **Ключі нод не перейменовуються.** Збережені workflow шукають ноду за `type`, тому, наприклад, `DepthLook*` лишились із попереднього окремого паку. Змінюються лише категорія меню (`StepVisionKit/<Розділ>`) і відображувана назва.

15. **Кожен вхід має `tooltip`, кожна нода — `DESCRIPTION`.** Підказка пояснює, що змінює вхід і в який бік; опис ноди — одне-два речення, що вона робить і з чим зʼєднується. Українські тексти — у `web/i18n/uk.json` (`nodes[ключ].display_name / description / inputs[імʼя].tooltip / label`).
16. **Назва — «Назва · варіант»** (Depth Look · Video, Detect Objects · YOLO, Save Video · HDR). Дужок і пояснень у назві немає, пояснення — в `DESCRIPTION`.
17. **Ноди без власного UI беруть спільну картку `web/svk_cards.js`.** У таблицю `MAIN` пишуть 3–5 головних віджетів у порядку картки, решта сама йде під «ще», тож новий вхід не губиться. `null` — усі віджети на видноті (коли їх ≤3). Ноди, під віджетами яких Comfy показує збережені картинки, або ноди з власною кнопкою стоять у `COLOR_ONLY`: лише колір ноди, картки поверх немає.
18. **Текстові поля й колір** — через той самий `control()`: рядок STRING стає полем вводу, а `opts.color` додає пікер кольору. Окремих віджетів-кнопок під колір немає.
19. **Гейт `depth_look/tests/ui_widgets_gate.py`** ловить вхід без місця в UI (Depth Look, Camera Realism) та одруківку в `MAIN` спільної картки. Запускати перед комітом UI.

## Анатомія картки

```
┌ кадр / превʼю (утримати = оригінал)        ┐
│ [плитки луків → гортаються вбік]           │
│ ефекти: чіпи, переносяться на новий рядок  │
│ сила луку ━━━━━━━━○──  80%                 │
│ ⫶ ще                                       │  ← рідкісне: розмір, роздільність, глибина
└ назва ноди (Nodes 2.0 — внизу)             ┘
```
