# Depth Look — ноди «Depth Look · повний / простий / відео» (StepVisionKit/Depth)

Лінзовий блюр за глибиною + кольорова палітра, силует, серпанок, шлейф, halation, зерно.
З 24.10.2026 живе в паку **ComfyUI-StepVisionKit** (`depth_look/`), раніше — окремий пак `comfy_depth_look`.
Рушій `look.py` / `look_params.py` / `look_api.py` / `tune.html` лежить у цій же теці; `look_proto/` бере його
через симлінки (CLI `look_tool.py` працює як був). Потрібні лише numpy + cv2 (+ torch від Comfy).

## Встановлення

Нічого окремо: нода приходить разом з ComfyUI-StepVisionKit, категорія меню `StepVisionKit/Depth`.
Ключі нод (`DepthLook`, `DepthLookSimple`, `DepthLookVideo`) не змінено, тож збережені workflow відкриваються як були.

## Вигляд ноди (24.10.2026)

Інтерфейс за правилами паку `../CONVENTIONS_UI.md` (спільне: `web/svk_ui.css` + `web/svk_ui.js`):
нативні віджети сховані (значення зберігаються у workflow), пояснення — лише в підказках на наведенні,
кнопки — іконки в один ряд, рідкісне — під «ще». Перевірено в режимі Nodes 2.0.

- **Простий:** кадр (утримати = оригінал) → плитки луків з людськими назвами → чіпи ефектів (переносяться,
  тап = вкл/викл, тягни або колесо = сила 0..2) → «Сила луку» → «ще». Картка гортається колесом усередині.
- **Повний:** тюнер на всю ноду; під превʼю — ряд іконок (фокус, герой, тло, глибина, оригінал, масштаб, лупа),
  знизу — повний екран, «превʼю / фінал» і «ще» (розмір, `max_side`, рівні глибини, чистка, напрям глибини).
- **Відео:** стрічка кадрів з програванням, `fps`, «превʼю / фінал» і 4 головні повзунки
  (рух кольору, швидкість руху, пульс світла, живе зерно); решта анімації — під «ще». Нода — вихідна
  (`OUTPUT_NODE`), тож рахується й без збереження після неї.
- **Сила луку** (`look_mix`) з простої ноди йде через `grade` у повну й відео-ноду: усі три змішують з оригіналом
  однаково (у лозі — «сила луку 0.70»).

## Входи

- `image` — кадри (B,H,W,3).
- `depth` — карта глибини (1 кадр на всі або B кадрів; береться канал 0; розмір не обовʼязково збігається).
- `preset` — пресет з `depth_look/presets` (за замовч. `look_v1`).
- `clean_depth` — True: сира глибина чиститься (`prepare_depth`, кадр = guide); False: глибина вже чиста 0..1.
- `depth_light_is_near` — True: світле = близько; False — інвертувати.
- `overrides` (опц.) — JSON поверх пресету, напр. `{"silhouette":1.0,"trail":0.5}`.
- `palette` (опц.) — замінює палітру: JSON `[[t,[r,g,b]],...]` (0..1) або `0:#0b0604, 0.5:#c54202, 1:#ffc9a0`.

- `fps` (опц., 24) і `start_time` (опц., 0) — кадр i отримує `time = start_time + i/fps` секунд; від `time`
  залежать анімаційні повзунки: `grain_animate` (нове зерно щокадру), `warp_speed` (хвиля «дихає»),
  `glow_pulse`/`pulse_hz` (пульс глоу та іскор), `haze_drift` (серпанок пливе), `trail_wobble` (хитання шлейфу).
  Задаються через `overrides`, напр. `{"grain_animate":1,"glow":0.8,"glow_pulse":0.4,"warp_speed":0.5}`.

Вихід — `image` того ж розміру. Прогрес друкується кожні 10 кадрів.

## Як підключити глибину

Вхід `depth` — будь-який IMAGE з картою глибини: ноди Depth Anything / DA3 / MiDaS / Marigold тощо
(канал 0; 8/16 біт, 1/3/4 канали; розмір і навіть трохи інше співвідношення сторін — не проблема, глибина
тягнеться до кадру). **Світле = близько**; якщо нода віддає навпаки (світле = далеко) — вимкни
`depth_light_is_near`. Кадри можуть бути будь-яких пропорцій (портрет, горизонталь, квадрат); радіуси ефектів
рахуються від довгої сторони. Орієнтація depth має збігатися з кадром (портрет-depth на горизонтальний кадр = помилка).
Новинки в `overrides`: `blur_amount` (0..3, множник блюру), `blur_target` (0..1: 1 = герой різкий, 0 = різке тло,
-1 = як у пресеті), `glow*`, `spark*` (точковий глоу, `spark_rays` 4/6/8 = зірка).

## Пресети

Редагуються в тюнері: `look_tool.py tune` (у `look_proto`). Нові пресети зʼявляються в списку після
перезапуску Comfy. `look_v1` зафіксований (LOCKED) — зберігай під іншим імʼям.

## Вбудований тюнер у ноді (23.10.2026)

Нода має всередині той самий тюнер, що й `look_tool.py tune`: повзунки, редактор градієнта з бібліотекою,
піпетка, превʼю. Окремої вкладки браузера не треба.

- **Кадр** береться лише з вхідних сокетів `image` + `depth` (файлів вибирати не можна). Після першого запуску графа нода
  кешує до 8 рівномірно вибраних кадрів батча (float16, `_cache/comfy_node_<id>_*`), і превʼю рахується з них.
  Перед першим запуском тюнер показує «запусти граф раз, щоб превʼю взяло твій кадр». Після кожного запуску превʼю саме
  підхоплює новий кадр.
- Слайдер **«кадр N»** гортає кешовані кадри; повзунок `time` = `start_time + N/fps`.
- Параметри пишуться у прихований віджет `params_json` і зберігаються у workflow. Непорожній `params_json` має
  пріоритет над `preset`/`overrides`/`palette`; зміна `preset` у ноді очищає `params_json`.
- Градієнти й пресети — ті самі `gradients/` і `presets/`, що й в автономному тюнері.
- `max_side` (0 = рідний): look рахується на зменшеному кадрі й росте назад — для довгих відео на 8 ГБ.
- `depth_levels`: `clip` (за замовч.) — спільні рівні глибини з усього кліпу (`look.clip_levels`), без мерехтіння;
  `frame` — покадровий розтяг, як раніше. Працює лише при `clean_depth`.
- Зерно живе: `seed` кадру = `seed` + номер кадру батча; `warp_seed` стала.
- Маршрути Comfy: `/depth_look/ui`, `/depth_look/api/<node>/...` (логіка — `look_api.py`, спільна з автономним тюнером).
